① 描述层

客户价值结构

方法：两阶段 RFM 分层（先切单次/复购，再层内分类）
数据：9.3 万客户的 R/F/M 三维度

发现：48.5% 高价值单次客贡献 76% GMV，复购率仅 3%
② 诊断层

为什么不复购

方法：6 个假设检验（H1 画像差异 / H6 体验→复购 / H4-H5 履约归因 / H2 大促 / H3 品类量价）
方法：Mann-Whitney U + 卡方 + 效应量

发现：超时让评分暴跌（4.29→2.46），但不影响复购率——复购低是结构问题，不是体验问题
③ 预测层

谁会复购

方法：首单特征训练分类模型（LR + LightGBM），规避数据泄漏
评估：AUC / PR-AUC / Top-K 命中率

发现：AUC≈0.62（弱可学），Top10% 可抓 17% 复购——精准小池可行，全量投放不行
④ 处方层

钱怎么投

方法：基于前三层证据做预算分配 + 分人群运营动作
产出：留旧池 ROI 监控指标

结论：主投拉新（80%），留旧设独立小池（20%）只投 Top10% 高潜客户

这个项目展示了什么：不是跑一遍流程，而是用"假设→验证→修正"的方式做分析——从 EDA 发现复购率 3% 这个反常事实出发，逐层追问"为什么"，最终用数据回答"钱该怎么投"。每一步的结论都直接影响下一步的方法选择。

两阶段 RFM：先切单次/复购，再各层内部分类

核心发现：48.5% 的高价值单次客（高潜新客+高价值唤醒）贡献了 80% 的 GMV。其中高潜新客（近期活跃、高额、仅一次购买）是复购转化的首选目标人群；高价值唤醒（沉睡但高额）是最大流失风险。
为什么 97% 的客户只买一次？
结构说 vs 体验说：是市场使然，还是履约问题？

H6体验→满意：超时订单评分暴跌

准时单平均 4.29 分，超时单仅 2.46 分

满意→复购：评分高低几乎不影响复购率

低分/中分/高分客户复购率 2.8%~3.1%，无差异
关键结论：超时确实让客户不满（评分从 4.29 跌到 2.46），但不满并不导致不复购——高/中/低分客户的复购率都在 3% 左右。这说明复购率低是结构性问题（巴西电商市场特征），而非履约体验问题。改善履约是防守项，不是复购增长杠杆。

模型结论

能做什么、不能做什么

✓ 能做：对高首单额 + 近期首购 + 配送有问题的客户做精准 30 天窗激励，Top10% 有 1.7 倍提升。

✗ 不能做：AUC 0.62 远低于强预测，无法大规模预测谁会复购。这再次印证"复购是结构性现象"。

策略含义：留旧不应该全量铺开，而应设独立小预算池，只对打分 Top10% 精准投放。
