# 项目主线与逻辑链

> 一句话定位：把"复购率 3.0%"这个观察，升级成"留旧还是拉新"这个可证伪、有决策在背后的业务问题。

## 一、问题陈述

### 一句话版

> Olist 平台 97% 的客户两年内只下单一次（复购率 3.0%），其中 48.5% 的高价值单次客贡献了 76% 的 GMV。这一"一次性买家主导"的收入结构，是市场结构使然（不可改），还是平台履约体验（超时、差评）所致（可改善）？平台的运营资源，该投"拉新"还是"留旧"，投给谁、如何投？

### 为什么这是个好问题（自检四条）

1. **可证伪**："结构说"与"体验说"可以分别检验——若复购/单次差异集中在客单与品类（结构性），支持结构说；若集中在超时率与评分（体验性），支持体验说。
2. **背后有真实决策**：拉新预算 vs 留旧预算，是平台每个月都要做的资源分配。
3. **数据能回答**：订单 → 履约（5 个时间戳）→ 评分（分数 + 评语）→ 复购的完整链条是 Olist 数据集独有优势，绝大多数电商分析案例拿不到"履约质量"这一环。
4. **诚实标注边界**：本数据集**只能证明"相关/可预测"，不能证明"因果"**（无营销渠道、无价格历史、无 A/B）。
### 四个子问题（对应逻辑链四层）

| 子问题 | 一句话 |
|---|---|
| Q1 描述 | 客户价值结构是什么样？收入由谁贡献？ |
| Q2 诊断 | 为什么 97% 只买一次？结构原因与体验原因各占多少？ |
| Q3 预测 | 哪些一次性买家最可能复购？哪些高价值客户正在流失？ |
| Q4 处方 | 资源投"拉新"还是"留旧"？投给谁、投多少、怎么投？ |

## 二、逻辑链：描述 → 诊断 → 预测 → 处方

| 层 | 要回答的问题 | 方法 | 关键证据 / 产出 | 状态 |
|---|---|---|---|---|
| ① 描述 | 客户价值结构？谁贡献收入？ | 两阶段 RFM 分层 | 97% 单次客 / 48.5% 高价值客 = 76% GMV → `rfm_report.md` | ✅ 完成 |
| ② 诊断 | 为什么只买一次？结构 vs 体验 | 画像对比(H1) + 评分→复购(H6) + 低分评语文本 + 履约归因(H4/H5) + 增长分解 | 超时单评分 2.46 vs 准时 4.29；新客 vs 老客 GMV 贡献 → 画像报告 | ✅ 完成 |
| ③ 预测 | 谁会复购？谁在流失？ | 复购预测模型（**仅首单特征，规避数据泄漏**）+ 全期 vs 30 天窗对照 | 全期 AUC≈0.60、30 天窗≈0.62（弱可学）；Top-K 前 10% 抓 21% 复购 → 留旧有**微弱抓手** | ✅ 完成 |
| ④ 处方 | 投拉新还是留旧？投谁、投多少？ | 分人群运营动作 + 预算分配 + 交互式仪表盘 | 拉新 80% / 留旧 20%；高潜新客 P0 投 40% 留旧预算 → [dashboard/](../dashboard/) | ✅ 完成 |

**这条链的引擎在 ② 诊断层**：它把"复购率 3%"拆成"改得了的"和"改不了的"两部分，是整份作品体现"分析思维"而非"流程堆砌"的地方。

## 三、假设重映射：H1–H6 服务主线

原 EDA 的 6 个假设是"并列的发现"，现重排为"服务主线的证据链"，每个假设都回答主线的一个侧面：

| 假设 | 原表述（提炼） | 主线中的新定位 | 服务子问题 |
|---|---|---|---|
| **H6（升为核心）** | 超时单评分显著低于准时（4.29 vs 2.46）；高评分客户复购率更高 | **"体验 → 满意 → 复购"因果链的直接检验，是"结构 vs 体验"之争的胜负手** | Q2 诊断 |
| H1 | 复购 vs 单次在客单价、品类、地区存在显著差异 | 画像差异：差异在客单/品类 → 支持结构说；在体验/评分 → 支持体验说 | Q2 诊断 |
| H4 | 超时与跨州距离相关，订单集中于东南部 | 体验问题出在哪、能否修（距离是结构性的） | Q2→Q4 |
| H5 | 超时集中在特定州/品类/卖家，区分"承诺过紧"与"物流延误" | 体验问题出在哪、能否修（物流延误是可改善的） | Q2→Q4 |
| H2 | 大促（黑五）订单的客单价、超时率、差评率劣于日常 | 拉新获客的**质量**如何——支撑"拉新 vs 留旧"的资源配置 | Q4 处方 |
| H3 | 品类存在"量大价低/量小价高"的量价组合差异 | 留旧时该把客户导向哪些（高客单/高复购）品类 | Q4 处方 |

### 新增两个证据（补上主线缺口）

1. **低分评语文本挖掘**（H6 的定性补充）：1–2 星评语里客户到底因什么不满（物流慢 / 商品不符 / 卖家服务），给"体验 → 流失"提供文字证据，让归因不止于相关性。
2. **增长分解**（结构说的直接量化）：把 GMV 拆成"新客首单贡献" vs "老客复购贡献"，画 cohort 留存曲线。**实测（`09_growth_decomposition.py`）：两年 GMV 97.0% 来自新客首单、仅 3.0% 来自老客复购；各 cohort 第 3 个月留存率仅 0.1%–0.4%，后续月份更低**——平台是极端新客驱动型、复购底盘几乎为零，是"结构说"最硬的数字，也是 Q4（投拉新还是留旧）的决策底座。
3. **复购预测模型**（预测层的结构说验证，`10_repeat_model.py` / `10b_repeat_model_window.py`）：用**首购时刻即可得**的首单特征（金额/评分/超时/配送/承诺差/品类/州/月份）预测"是否复购"，并做了**防数据泄漏设计**（首版误用累计量特征致 AUC=1.0，已修正为仅用首单特征，AUC 回落至真实水平）。**实测：全期复购 AUC≈0.60（LightGBM）、首购后 30 天窗复购 AUC≈0.62，均远低于强预测（0.8+）**——复购从首单特征几乎不可预测，再次印证"结构说"；但 30 天窗 Top-K 前 10% 客户可抓 **21% 复购**（盲投约 10%），留旧对**高首单额 + 近期首购 + 配送承诺差**客户存在微弱抓手，可做精准 30 天窗激励。

## 五、方案层信度与验证设计

> ⚠️ **信度边界**：本分析基于 Olist 公开数据集，**只能证明"相关/可预测"，不能证明"因果"**（数据集无营销渠道、价格历史、竞品、促销日历数据，未做 A/B 实验）。"复购率低为结构性问题"是 H1~H6 统计检验、增长分解与复购模型共同支撑的**推断**，而非实验证明——这是数据集的客观限制，已在结论中诚实标注。

**方案层为可证伪假设**：拉新 80% / 留旧 20% 与分人群运营动作，是"基于分析的建议"，真实效果需经投放验证，不宣称已实现收益。

**A/B 验证设计（落地路径）**：

- **假设**：对高潜新客在首购 30 天内发放复购券 / 定向召回，目标人群复购率显著提升，且留旧池 ROI > 1
- **设计**：随机分组（实验/对照）｜主指标：复购率、留旧 ROI｜次要指标：客单价、GMV 增量｜样本量：按 3% 基线复购率与最小效应量估算｜周期：≥30 天完整购买窗口｜决策阈值：ROI>1 保留留旧池，否则收缩回拉新｜防污染：避开大促窗口、不与自然促销重叠
- **闭环**：30 天窗滚动打分 → 投放 → 追踪复购 → 回算 ROI → 反馈预算与模型（验证-复盘-迭代）

**反事实基线**：留旧增量 = 实验组 GMV 增量 − 对照组自然增长；若只投拉新不投留旧，GMV 预期维持新客驱动现状，留旧增量需显著高于该基线才值得保留。

**业务场景边界**：数据集无法识别渠道缩减/自然衰减、价格策略、竞品冲击、库存限制等外部因素；黑五等大促脉冲已通过 H2 单独识别，其余正常波动需结合业务背景判断，避免将正常波动误判为业务问题。
